# Mini Project 03: File Manager

## Objective

Build a simple file management utility using Python.

---

## Features

1. Create File
2. Read File
3. Append Content
4. Delete File
5. Rename File
6. Exit

---

## Requirements

- Handle missing files gracefully.
- Prevent program crashes using exception handling.
- Display meaningful error messages.
- Use pathlib or os module where appropriate.

---

## Bonus Challenge

Add a feature to list all files inside a directory.

---

## Concepts Practiced

- File Handling
- Exception Handling
- Modules
- Path Operations
