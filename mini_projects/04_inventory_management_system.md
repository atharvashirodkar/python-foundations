# Mini Project 04: Inventory Management System

## Objective

Build an inventory tracking system for a small store.

---

## Features

1. Add Product
2. View Products
3. Search Product
4. Update Product Quantity
5. Delete Product
6. Exit

---

## Product Information

Store:

- Product ID
- Product Name
- Price
- Quantity

---

## Requirements

- Product IDs must be unique.
- Quantity cannot be negative.
- Validate user input.
- Organize code using functions.

---

## Bonus Challenge

Store inventory data in a JSON file.

---

## Concepts Practiced

- Dictionaries
- Lists
- Validation
- Functions
- File Handling
