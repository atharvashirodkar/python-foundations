# Mini Project 02: Student Record System

## Objective

Create a system to manage student records using Python dictionaries and lists.

---

## Features

1. Add Student
2. View Students
3. Search Student
4. Update Student
5. Delete Student
6. Exit

---

## Student Information

Store:

- Student ID
- Name
- Age
- Course

---

## Requirements

- Student IDs must be unique.
- Search using Student ID.
- Update existing records.
- Delete records safely.
- Keep the program menu-driven.

---

## Bonus Challenge

Store data in a JSON file.

---

## Concepts Practiced

- Lists
- Dictionaries
- Functions
- Loops
- File Handling
