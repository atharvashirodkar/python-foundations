# Mini Project 01: Calculator Application

## Objective

Build a menu-driven calculator application using Python functions.

---

## Features

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Power
6. Square Root
7. Exit

---

## Requirements

- Use functions for each operation.
- Handle invalid inputs.
- Prevent division by zero.
- Allow multiple calculations until the user exits.
- Display results clearly.

---

## Concepts Practiced

- Functions
- Conditionals
- Loops
- Exception Handling
- Built-in Modules
